Backup / restore
Changes autosave in this browser on this device, so refreshing or reopening the page keeps your rankings and picks. That save doesn't cross devices or browsers on its own — either use Cross-device sync below (recommended), or Export here before switching to your laptop and Import there.
Cross-device sync (GitHub)
Uses your own GitHub repo as the sync point. Once connected, opening the page, switching back to this tab, and a background check every 30 seconds all automatically pull the latest from GitHub — and every change you make pushes back out. Your phone and laptop stay in sync on their own, no manual "Sync now" needed. Your token is stored only in this browser and used solely to talk to GitHub directly — it's per-browser, so each browser you use it in needs the token entered once.
Not connected.
How to create the token (one-time, ~1 minute)
1. On github.com, tap your profile photo (top right) → Settings.
2. Scroll to the bottom of the left sidebar → Developer settings.
3. Personal access tokens → Fine-grained tokens → Generate new token.
4. Under Repository access, choose "Only select repositories" and pick this repo.
5. Under Permissions → Repository permissions, find "Contents" and set it to Read and write.
6. Tap Generate token, then copy the token shown (starts with github_pat_) — GitHub only shows it once.
7. Paste it into the Access token field above and tap Connect & sync.
